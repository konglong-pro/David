# David

David 是一个零依赖的 Chrome Manifest V3 扩展，可以把网页选区或主流 AI 对话转换为 Markdown，并直接写入剪贴板。

## 当前功能

- 完整对话模式支持：
  - `https://chatgpt.com`
  - `https://chat.openai.com`
  - `https://gemini.google.com`
  - `https://claude.ai`
- 选区模式适用于任意普通 HTTP/HTTPS 网页。
- 点击 David 时，选区模式优先：
  - 页面有选区：只复制选中的内容。
  - 页面没有选区且属于受支持的 AI 站点：复制当前已加载的完整对话。
  - 其他网页没有选区：提示先选择内容。
- 完整对话使用 `## User` 和 `## Assistant` 分隔各轮。
- 不添加对话标题、来源、平台、URL、时间或其他元数据。
- 保留常见 Markdown 结构：标题、粗体、斜体、删除线、链接、代码、列表、引用、表格和 KaTeX 数学公式。
- 所有处理都在当前浏览器页面完成；扩展不发送网络请求，也不保存对话内容。

## 安装或更新

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 首次安装时点击“加载已解压的扩展程序”，选择 `E:\David`。
4. 已安装旧版本时，在 David 卡片上点击“重新加载”。
5. 建议把 David 固定到浏览器工具栏。

## 使用

### 复制完整 AI 对话

1. 打开一个受支持的 AI 对话，并等待回答生成完成。
2. 确认页面上没有保留文字选区。
3. 点击工具栏中的 David 图标。
4. 页面右下角显示复制成功提示后，粘贴到任意 Markdown 编辑器。

输出示例：

````md
## User

请解释这段代码。

## Assistant

下面是解释：

```python
print("hello")
```
````

### 复制网页选区

1. 在任意普通网页中选中需要的内容。
2. 点击 David 图标。
3. David 只会转换并复制该选区，不添加角色标签或页面信息。

## 已知限制

- 完整对话模式只复制当前对话分支以及页面 DOM 中已经加载的消息。特别长的对话建议先滚动到顶部，确保旧消息已加载。
- 图片、上传附件和 Canvas/Artifact 等非文本内容不会被下载；普通网页图片只保留可访问 URL 或替代文本。
- AI 网站更新页面结构后，对应适配器可能需要随扩展版本调整。
- Claude 的当前适配器包含多组结构回退；本地浏览器检查遇到 Cloudflare 验证，因此发布前仍建议在真实 Claude 对话页做一次人工确认。
- 当前没有“只复制最后一条回复”、设置页或右键菜单。

## 文件

- `manifest.json`：Manifest V3 配置与最小权限。
- `background.js`：处理工具栏点击并按需注入复制脚本。
- `content.js`：选择模式、站点适配、Markdown 转换、剪贴板写入和结果提示。
