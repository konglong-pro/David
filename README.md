# David

David 是一个零依赖的 Chrome Manifest V3 扩展，可以把网页选区或主流 AI 对话转换为 Markdown，并直接写入剪贴板。

## 当前功能

- 完整对话模式支持：
  - `https://chatgpt.com`
  - `https://chat.openai.com`
  - `https://gemini.google.com`
  - `https://claude.ai`
- 选区模式适用于任意普通 HTTP/HTTPS 网页。
- 点击 David 会打开英文操作弹窗：
  - `Quick Copy`（快捷键 `C`）：优先复制页面文字选区，否则复制完整 AI 对话。
  - `Select Messages`（快捷键 `S`）：在受支持的 AI 对话中选择单条消息或连续消息区间。
- `Quick Copy` 的处理顺序：
  - 页面有选区：只复制选中的内容。
  - 页面没有选区且属于受支持的 AI 站点：复制当前已加载的完整对话。
  - 其他网页没有选区：提示先选择内容。
- `Select Messages` 提供 `Copy`、`Select all`、`Start over` 和 `Cancel` 控件，并在页面上高亮当前区间。
- 完整对话使用 `## User` 和 `## Assistant` 分隔各轮。
- 不添加对话标题、来源、平台、URL、时间或其他元数据。
- 保留常见 Markdown 结构：标题、粗体、斜体、删除线、链接、代码、列表、引用、表格、Mermaid 代码块以及行内/块级数学公式。
- 所有处理都在当前浏览器页面完成；扩展不发送网络请求，也不保存对话内容。

## 安装或更新

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 首次安装时点击“加载已解压的扩展程序”，选择 `E:\David`。
4. 已安装旧版本时，在 David 卡片上点击“重新加载”。
5. 建议把 David 固定到浏览器工具栏。

## 使用

### 复制完整 AI 对话

1. 打开一个受支持的 AI 对话，并等待回答生成完成。
2. 确认页面上没有保留文字选区。
3. 点击工具栏中的 David 图标。
4. 点击 `Quick Copy`，或直接按 `C`。
5. 页面右下角显示复制成功提示后，粘贴到任意 Markdown 编辑器。

输出示例：

````md
## User

请解释这段代码。

## Assistant

下面是解释：

```python
print("hello")
```
````

### 复制网页选区

1. 在任意普通网页中选中需要的内容。
2. 点击 David 图标。
3. 点击 `Quick Copy`，或直接按 `C`。
4. David 只会转换并复制该选区，不添加角色标签或页面信息。

### 复制部分 AI 对话

1. 打开一个受支持的 AI 对话，点击 David 图标。
2. 点击 `Select Messages`，或直接按 `S`。
3. 点击一条消息可选择单条消息；再点击另一条消息可选择两者之间的连续区间。可以先点后面的消息，再点前面的消息。
4. 点击 `Copy`，或按 `Enter` 完成复制。`Escape` 可随时退出。

弹窗中也可以使用 `Tab` 切换选项，再按 `Enter` 执行。

## 已知限制

- 完整对话模式只复制当前对话分支以及页面 DOM 中已经加载的消息。特别长的对话建议先滚动到顶部，确保旧消息已加载。
- 部分对话目前只支持连续消息区间，不支持任意、不相邻的多条消息组合。
- 图片、上传附件和 Canvas/内嵌 SVG 图表等非文本内容不会被下载；可访问图片 URL、图注和 Mermaid 源码等可转换部分会保留。
- AI 网站更新页面结构后，对应适配器可能需要随扩展版本调整。
- Claude 的当前适配器包含多组结构回退；本地浏览器检查遇到 Cloudflare 验证，因此发布前仍建议在真实 Claude 对话页做一次人工确认。
- 当前没有设置页、右键菜单或全局快捷键。

## 文件

- `manifest.json`：Manifest V3 配置与最小权限。
- `background.js`：接收弹窗命令并按需注入页面脚本。
- `popup.html` / `popup.css` / `popup.js`：英文操作弹窗与键盘快捷键。
- `content.js`：消息区间选择、网页选区、站点适配、Markdown 转换、剪贴板写入和结果提示。
